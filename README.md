# FrogEgg Merge

DirectX 11과 C++로 만든 수박 게임 방식의 2D 물리 합성 게임입니다. 플레이어는 떨어뜨릴 알을 좌우로 움직여 같은 레벨끼리 합성하고, 더 높은 단계의 알과 점수를 얻습니다.

## 주요 기능

- 같은 레벨의 알 충돌 시 다음 단계로 합성
- 중력, 경계 충돌, 반발, 마찰을 적용한 2D 물리 시뮬레이션
- 물에 잠긴 정도에 따른 부력 및 유체 저항 표현
- 합성 시 팝 애니메이션, 물보라·플래시·물방울 파티클, 효과음 및 게임패드 진동
- 다음 알 미리보기와 보관/교환 기능
- 게임 오버, 재시작, 메인 메뉴 및 로컬 리더보드
- 마우스와 XInput 게임패드 조작 지원

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 좌클릭 드래그 | 떨어뜨릴 알을 좌우로 이동 |
| 마우스 좌클릭 놓기 | 알 떨어뜨리기 |
| 마우스 우클릭 | 현재 알을 보관 슬롯과 교환 |
| 게임패드 왼쪽/오른쪽 스틱 | 알 좌우 이동 |
| 게임패드 A | 알 떨어뜨리기 |
| 게임패드 B | 알 보관/교환 |
| 게임패드 D-Pad | UI 조작으로 포커스 이동 |

## 게임 규칙

1. 시작 알은 정해진 낮은 레벨 범위에서 무작위로 나옵니다.
2. 같은 레벨의 알 두 개가 닿으면 하나의 상위 레벨 알로 합성됩니다.
3. 합성 단계에 따라 점수가 누적됩니다.
4. 떨어진 알이 상단 게임 오버 라인에 닿으면 게임이 끝납니다.
5. 보관 기능은 짧은 쿨다운 이후 다시 사용할 수 있습니다.

## 프로젝트 구조

```text
src/
├─ App/          애플리케이션 초기화 및 메인 루프
├─ Game/         게임 상태, 규칙, 과일 데이터, 리더보드
├─ Physics/      공 물리, 충돌 감지 및 해결
├─ Rendering/    DirectX 11 렌더러, 머티리얼, 배경/알/파티클 렌더링
├─ Animation/    합성 팝 애니메이션
├─ Particle/     합성 파티클 시스템
├─ Input/        XInput 게임패드 입력
├─ UI/           ImGui 기반 메뉴 및 HUD
├─ Audio/        효과음 재생
└─ Platform/     Win32 윈도우 처리
assets/          텍스처
shaders/         HLSL 셰이더
sound/           효과음
data/            리더보드 저장 데이터
```

### 설계 의도

- `GameApplication`은 초기화와 프레임 실행 순서만 조정합니다.
- `GameSession`은 알 생성·드롭·합성·점수·게임 오버처럼 게임 규칙과 상태를 관리합니다.
- `GameController`는 입력을 게임 행동으로 변환하여, 입력 장치가 바뀌어도 게임 규칙을 유지할 수 있게 합니다.
- `PhysicsWorld`는 물리 및 충돌만 담당하고, 합성 여부는 `GameSession` 콜백으로 판단합니다. 물리와 게임 규칙을 분리한 구조입니다.
- `URenderer`는 DirectX 11의 공통 자원을 관리하며, 배경·알·파티클 렌더러는 각 표현 책임을 나눠 가집니다.
- 과일 단계, 반지름, 점수와 물리 상수는 `FruitCatalog`, `GameConfig`에 모아 밸런싱과 확장을 쉽게 했습니다.

## 빌드 및 실행

### 방법

1. `Week0.slnx`를 Visual Studio에서 엽니다.
2. 원하는 구성(예: `Debug | x64`)을 선택합니다.
3. 솔루션을 빌드하고 실행합니다.
