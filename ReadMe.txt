Ball Drawing (Ball Brush)

- 공으로 그림을 그릴 수 있는 기능을 만들어 봤습니다.
- 마우스 왼쪽 버튼을 클릭 후 드래그하면 경로에 따라 작은 공들이 생성됩니다.
- 마우스가 빠르게 이동해서 빈틈없이 공을 채웁니다.
- 그림용 공은 따로 배열에 보관하고 있고, 중력과 충돌에 영향을 받지 않아 그린 위치에 고정되도록 했습니다.
- Clear Drawing 버튼으로 공을 모두 지울 수 있습니다.

Black Hole

- Enable Black Hole을 켜고 화면에서 마우스 오른쪽 버튼을 누르고 있으면 해당 위치에 블랙홀이 생성됩니다.
- 물리 공은 마우스 위치를 향해 끌려갑니다.
- 블랙홀 중심에서 힘이 폭주하지 않도록 최대 가속도를 제한했습니다.
